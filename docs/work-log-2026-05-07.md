## 一、主要工作

### 1. 解决 RViz 鼠标交互失效（耗时最长）

**问题**：嵌入在 PyQt5 中的 RViz 3D 视图可以正常显示网格和模型，但无法用鼠标旋转、缩放、平移。

**排查过程**：
- 创建纯 C++ 测试程序，排除了 PyQt5/sip 的事件传递问题
- 通过 eventFilter 确认鼠标事件已到达 RenderPanel 的 Qt widget 层
- 最终定位：`loadDisplayConfig()` 和 `manager->load()` 加载 `.rviz` 配置文件时会重置 View/Tool 配置，导致 MoveCamera 工具失效，鼠标操控无法工作

**解决方案**：
- 不调用 `loadDisplayConfig()` 或 `manager->load()`
- 改用 `manager->createDisplay("Grid")` 和 `manager->createDisplay("TF")` 手动创建基础显示
- 保留 VisualizationFrame + winId + setMouseTracking + MoveCamera 工具激活的完整初始化序列

### 2. 完成地面站 UI 框架

按照设计方案 `docs/qt-rviz-station-plan-B.md` 实现了完整的界面布局：

```
┌──────────────────────────────────────────────────────────────┐
│ [菜单栏: 连接|机器人|录制|视图|帮助]                           │
│ [工具栏: 连接状态|Broker|在线数|FPS|录制|急停按钮]             │
├──────────────┬───────────────────────┬──────────────────────┤
│ 左侧面板      │     中间 3D 视图       │     右侧面板          │
│ 机器人 列表   │     RViz RenderPanel  │  Display(RViz原生)    │
│ 命令面板      │                       │  传感器摘要           │
│ 配置(传输/编队)│                      │  发送数据             │
│ 事件列表      │                       │  流量监控             │
├──────────────┴───────────────────────┴──────────────────────┤
│ [状态栏: 话题数|MQTT流量|录制状态|ROS Master]                 │
└──────────────────────────────────────────────────────────────┘
```

**已实现功能**：
- 菜单栏：连接/机器人/录制/视图/帮助
- 工具栏：连接状态指示、Broker地址、在线机器人数、FPS、录制计时、红色急停按钮
- 状态栏：话题订阅数、MQTT收发流量、录制状态、ROS Master 连接状态（实时检测）
- 机器人列表：在线/离线状态、电量、模式、订阅数，30秒心跳超时检测
- 命令面板：速度滑块（线速度/角速度）、模式切换（手动/自动/停止）、急停按钮
- RViz Display 面板：嵌入 RViz 原生 Display 树，支持 Add/Remove/属性编辑
- 事件面板：告警日志，四级颜色标签（CRITICAL/ERROR/WARNING/INFO）
- 传感器摘要面板：实时解析各类传感器数据
- 发送数据面板：支持对指定机器人话题推送 JSON/二进制数据
- 流量监控面板：各话题带宽实时统计
- 摄像头浮窗：RViz Camera/Image 类型 Display 自动弹出到 QDockWidget

## 二、技术要点

| 技术点 | 说明 |
|--------|------|
| RViz 嵌入 | 通过 C++ `extern "C"` 胶水层 + `ctypes.CDLL` 加载，`sip.wrapinstance` 嵌入 PyQt5 |
| 鼠标修复 | 不用 `loadDisplayConfig`，改用手动 `createDisplay` + MoveCamera 工具激活 |
| MQTT 线程安全 | paho-mqtt 回调 emit Qt Signal → 主线程 slot 更新 UI |
| 配置文件加载 | `start.sh` 启动时检查依赖、自动启动 roscore/mosquitto/bridge |
| display 创建 | C++ 侧手动 `createDisplay("Grid")` + `createDisplay("TF")` |
